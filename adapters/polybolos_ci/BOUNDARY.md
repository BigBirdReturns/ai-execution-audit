# Boundary of this directory

This directory qualifies a pinned public OSIRIS-derived Command Intelligence source and exercises generic AXM checkpoint, authority, partition, replay, and cabinet mechanisms around it.

It is **not** the canonical Polybolos mating contract. It does not reproduce Polybolos private Command Intelligence, COMMAND CORE, HOTL, BELARX, operator workflow, product interface, or internal schemas. The public-source qualification remains useful as a donor and stress harness, but it must not be presented as the Polybolos product or as proof of private implementation behavior.

The canonical external-system boundary is `adapters/polybolos/`. That adapter translates only explicit, confirmed external shapes into AXM-neutral contracts, records declared losses, preserves unknown-field evidence, and refuses live promotion while mappings remain provisional.
