      DECISION GLOSSARY
      What the outcomes mean
      
          
      
            
      Allow
      The message class is admitted by the current profile and receives a bounded ticket.
      
            
      Hold
      The message is valid but a required condition, such as local operator presence, is missing.
      
            
      Refuse
      The message or delivery is outside the current profile or repeats an identity already accepted.
      
            
      Safe state
      The offline authority lease expired before the action was evaluated.
      
            
      Human required
      Returning authority conflicts with the partition history and no mechanical winner is selected.
