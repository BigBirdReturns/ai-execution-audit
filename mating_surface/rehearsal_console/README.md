# Denied Communications Authority Rehearsal

This directory is a neutral, local interactive host for the standards-first mating surface. It is not an AXM surface, a Polybolos surface, a defense-product dashboard, or a browser reimplementation of the authority rules.

The browser renders state and submits bounded actions. `server.mjs` imports `MessageAuthorityRuntime` directly from `mating_surface/semantic/authority_sidecar.mjs`. The same server imports the canonical payload-opaque fault machine and the qualified semantic-conversation verifier. Source hashes and the packaged commit identity are shown in the interface and retained in every exported session receipt.

## Transaction

```text
schema-valid C2SIM fixture
        ↓
exact semantic receipt and payload digest
        ↓
MessageAuthorityRuntime imported server-side
        ↓
local deterministic transport scenario
        ↓
authority decision and admission ticket
        ↓
receiver replay or expiry decision
        ↓
returning-authority reconciliation
        ↓
replayable interactive session receipt
        ↓
neutral browser presentation
```

The standard XML is never sent to the browser. The browser contains no lease, authority, replay, or reconciliation decision rule. It can request a scenario action and render the server's receipt.

## Run from the repository

The host requires the evidence tree generated by the public C2SIM qualification workflow:

```bash
node mating_surface/rehearsal_console/server.mjs \
  --evidence qualification/c2sim-public-reference \
  --host 127.0.0.1 \
  --port 8787
```

Open `http://127.0.0.1:8787`.

## Controls

The console can cut the headquarters link, deepen the partition to total isolation, issue the retained schema-valid order and report, advance the authority clock, restore communications, and classify returning authority. It exposes the following fixture controls:

- local operator present or absent;
- duplicate order delivery on or off;
- delayed report on or off;
- offline lease of 0, 2, 5, or 10 steps;
- continuous, explicitly superseding, conflicting, or absent returning authority.

Reset is required to change the signed rehearsal lease. Other fixture controls may change before their corresponding action is issued.

## Evidence boundary

The host proves that the exact source module executes the interactive authority decisions and that an exported session receipt replays to the same identity. The transport conductor is local rehearsal infrastructure. The public C2SIM artifact remains a reference snapshot admitted for rehearsal only.

No target MAME runtime, MotionDeck installation, Polybolos implementation, operational C2SIM profile, fielded network, command authority, targeting, engagement, effector control, execution path, or weapons capability is claimed.
