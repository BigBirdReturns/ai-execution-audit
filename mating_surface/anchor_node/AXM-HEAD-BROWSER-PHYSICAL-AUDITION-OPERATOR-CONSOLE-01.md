## Execution mechanism

The generated Manifest V3 extension retains the exact probe as its only content script. Chromium installs that script at `document_start` in the page `MAIN` world, preserving the observation boundary admitted by PR #96 and carried into PR #102.

The operator console does not create a DOM relay, page event bus, `window.postMessage` channel, or injected bridge object. Those paths would let target-page code imitate command responses. The operator instead opens a Chromium side panel. The panel owns one long-lived extension port to the service worker. The service worker validates every command against the frozen contract, binds it to the active tab and an in-memory session, rejects stale or replayed request identifiers, and calls `chrome.scripting.executeScript` with `world: "MAIN"`. The executed function independently inspects the probe property descriptor, frozen API object, version, exact method denominator, capture schema, and byte ceiling before invoking one admitted method.

The target page never receives the extension port, session ledger, or service-worker return path. The service worker retains no private capture after responding. Closing the side panel destroys the in-memory session and request ledger.

## Validation and refusal law

The command contract applies exact-key validation before any page execution. It refuses unknown methods, missing or extra fields, arrays above the closed ceiling, commands above 65,536 encoded bytes, nonfinite numbers, wrong integer types, negative or excessive values, malformed SHA-256 references, invalid layer ranges, unknown partition modes, unknown pipeline roles, unknown receipt classes, raw URL or file coordinates, raw IPv4 identities, and malformed opaque member identifiers.

The following classes cannot enter a command envelope:

```text
prompt or completion bodies
token text
SDP or ICE addresses
credentials or secrets
response bodies
hostnames or local paths
raw URLs
supplier identity or supplier admission
packet terminal or named-human confirmation
mission, command, targeting, engagement, effector, or weapons authority
```

The service worker separately requires the active tab to remain the session target. A panel cannot silently continue operating an old tab after focus changes. Each request identifier is single-use within the session, including a failed request. The session expires after two hours or 512 accepted requests. No local, session, synchronized, IndexedDB, or cloud-backed storage API is used.
